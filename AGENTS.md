# Improvement Game Proposal Assay

This Lenticule Science micro-enterprise deterministically examines one bounded
improvement-game proposal. It does not design the game, implement it, decide
customer usefulness, mutate customer territory, or operate a market.

The assay accepts only an exact request crossing its advertised operation,
checks source, territory, economy, writable-root, and protected-oracle
relations, and returns a proposal-bound advisory review or typed refusal.
